<p><strong>DashNet's Best Gamers</strong> (sometimes abbreviated as <strong>DBG</strong>) is a Discord server created by [[Fractyl]] for organizing gaming events among members of DashNet. It has been used for playing many games, such as Jackbox party games, Minecraft, and Skribbl.io. The current server icon is the album cover of <cite>[[cookie-clicker-soundtrack|Cookie Clicker]]</cite> by C418.</p>
<p>DBG was started on December 25th, 2025. It originated from a Discord group chat named "dashnet minecrafters", which had only existed for about 11 hours when the server was created.</p>
